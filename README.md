# Local AI Chat

A browser-based chat app that talks to a local AI model (Llama 3.2 via Ollama) — built with Streamlit. Runs entirely on your own machine, no API costs, no internet required once set up.

## Features
- Real-time chat interface with message history
- Powered by a free, local LLM (no API key needed)

## Requirements
- Python 3
- [Ollama](https://ollama.com) installed, with the llama3.2 model pulled
